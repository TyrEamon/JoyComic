# JoyComic 全功能落地设计

**日期：** 2026-07-14
**状态：** 已获用户口头批准，待书面规格复核

## 目标

把现有展示壳与占位入口替换为可用功能，并修复漫画详情远端 JSON 类型不稳定导致的崩溃。全部工作在本地完成并验证后，仅向 `main` 推送一次。

## 范围

1. 修复禁漫/哔咔模型解析中的数字类型不稳定问题。
2. 首页接入真实双源内容分区、刷新、错误隔离与更多列表。
3. 分类页提供禁漫/哔咔顶部切换、真实分类 API、分页结果和筛选排序。
4. 完成本地及远端收藏同步与真实收藏页。
5. 完成历史记录页、继续阅读、删除和清空。
6. 完成章节下载、暂停/恢复/重试/删除、离线阅读和任务恢复。
7. 我的页面展示真实账号与本地统计。
8. 完成跟随系统/浅色/深色主题并持久化。
9. 完成缓存统计、清理与下载数据的独立删除入口。
10. 完成关于页和所有缺失路由。
11. 清除无行为按钮、假数据和功能占位；保留合理的加载与图片占位。

## 架构决策

### 统一源契约

扩展 `ComicSource`，由源适配层向 UI 提供统一的首页分区、分类描述、分类结果、收藏及图片加载能力。页面不得直接依赖禁漫或哔咔网络模型；确有协议差异时封装在各源适配器内部。

### 安全 JSON 转换

新增集中式 JSON 转换工具，数字字段接受 `int`、`double`、数字字符串及空值。远端模型不得对不稳定字段直接使用 `as int`。错误必须写入诊断日志并返回可读状态，而不是让页面崩溃。

### 页面状态

页面维持当前 Flutter/Provider 风格，不引入新的大型状态管理框架。双源 Tab 各自保留加载状态、分页状态和滚动位置。各首页分区独立失败，单源失败不阻塞另一源。

### 数据持久化

保留 SQLite 手写 SQL。通过幂等迁移增加历史、下载和收藏需要的元数据字段，兼容已有安装数据。SharedPreferences 保存主题和轻量设置。数据库、账号、收藏和历史不得被“清理缓存”删除。

## 功能设计

### 首页

- 编辑推荐、最近更新、禁漫热门、哔咔热门及源推荐分区使用真实接口。
- 支持下拉刷新、空状态、错误重试和“更多”列表。
- 卡片携带来源标识；点击进入对应源详情。
- 请求并发执行且错误隔离。

### 分类

- 顶部仅展示已启用源的“禁漫 / 哔咔”切换。
- 分类来自真实源 API，不使用硬编码假分类。
- 点击分类进入漫画结果页，而非漫画详情页。
- 结果页支持刷新、分页、加载更多、排序、错误重试和空状态。
- 源协议差异由 `jm.dart` 与 `picacg.dart` 适配。

### 收藏

- 合并本地收藏与已登录源远端收藏。
- 支持来源筛选、进入详情、取消收藏和跨页面即时刷新。
- 远端操作成功后再更新本地状态；离线时仍展示本地收藏。
- 未登录源展示明确登录入口。

### 历史

- 按最近阅读时间倒序展示漫画、来源、章节、页码与时间。
- 支持继续阅读、进入详情、单条删除和清空确认。
- 阅读进度更新保存恢复阅读所需完整元数据。

### 下载

- 详情页支持选择章节创建任务。
- 支持暂停、继续、重试、删除、任务去重和重启恢复。
- 下载使用源图片鉴权配置；禁漫图片执行必要重组。
- 已完成章节支持离线阅读。
- 删除任务与删除文件明确区分。

### 我的、主题、缓存、关于

- 我的页面读取真实登录信息和本地统计，移除硬编码账号。
- 主题支持系统、浅色、深色并立即生效、持久化，兼容旧布尔设置。
- 缓存页统计网络图片、Flutter 图片缓存、临时文件和日志；不删除用户数据或已完成下载。
- 已完成下载提供单独删除入口。
- 关于页展示名称、版本、免责声明、开源许可、项目入口和日志入口。

## 路由

新增或补全：

- `/history`
- `/favorites`
- `/about`
- `/category/:sourceKey/:categoryKey`
- 必要的源内容列表路由

删除未匹配路由自动伪装成功的占位行为；未知路由显示明确的 404/返回入口。

## 错误处理

- 网络、解析、鉴权、磁盘与数据库错误分别记录。
- 页面提供重试，不暴露原始堆栈。
- 远端数据字段缺失使用明确默认值；关键标识缺失时丢弃该条数据并记录日志。
- 收藏和下载采用可恢复状态，避免 UI 与本地状态不一致。

## 测试与验证

采用测试优先方式覆盖：

- JSON 数字安全转换和详情回归。
- 双源分类映射及无效分类过滤。
- 首页分区聚合与部分失败。
- 数据库迁移、收藏、历史 CRUD。
- 下载去重和状态迁移。
- 主题兼容迁移与缓存清理边界。
- 全项目本地导入路径扫描及 `git diff --check`。

若本机无 Flutter SDK，不能声称 Flutter 编译通过；在单次最终推送前完成所有可执行的静态验证。Codemagic 作为最终 iOS 编译证据。

## 非目标

- 不新增漫画源。
- 不更换状态管理框架或数据库引擎。
- 不重写阅读器主体视觉。
- 不在源码或界面标注库来源。
- 不把加载骨架、图片加载占位视为待删除功能占位。

## 交付与推送

允许开发期间创建本地提交。所有功能完成并通过可用验证后，统一执行一次 `git push origin main`。在此之前不向远端推送。
